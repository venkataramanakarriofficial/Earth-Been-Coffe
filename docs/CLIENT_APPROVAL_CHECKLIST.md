# EARTH BEEN COFFEE — Client Approval & Launch Checklist

## Items to request from the client

- [ ] Official vector logo (SVG ideally) and any icon/monogram lockups.
- [ ] Approved colour values, typography, graphic identity and brand deck.
- [ ] Approved homepage slogan, brand story, values and sourcing claims.
- [ ] Real product, stall, atmosphere and lifestyle photography with web usage rights.
- [ ] Official full drink names, descriptions, ingredient/allergen info when required, and GBP prices.
- [ ] Current/future stall addresses, operating dates/hours and verified Google Maps directions links.
- [ ] Confirmed business email for partnerships, collaboration and general enquiries.
- [ ] Approved social profile links.
- [ ] Domain owner, hosting owner, DNS administrator and privacy/contact policies as required.
- [ ] Written approval for use of a 3D animated coffee-cup hero and opening sequence.

## Visual and functional acceptance

- [ ] Logo rendering, cup branding and artwork confirmed against brand deck.
- [ ] Client approves all copy and images (illustrations to be replaced as desired).
- [ ] Mobile hero, menu and page navigation reviewed on actual phones.
- [ ] Confirmed menu data matches client menu and pricing.
- [ ] Locations, Google Maps links and opening hours verified before publish.
- [ ] Business mailto/social links work after the real details are added.
- [ ] Reduced-motion accessibility and static fallback tested.
- [ ] Chrome, Safari, Edge and Firefox basic functionality tested.
- [ ] Core Web Vitals tested after final production images/3D assets are installed.
- [ ] `npm run lint:types` and `npm run build` complete successfully in deployment environment.
- [ ] Add siteUrl, set up domain/HTTPS, favicon and SEO, then remove temporary noindex only after approval.
- [ ] Confirm privacy/legal text and any analytics consent requirements before enabling trackers.

## Handover

- [ ] Deliver repository access and latest ZIP/source archive.
- [ ] Deliver source asset rights and branding files from the client or licensed providers.
- [ ] Document who maintains menu/locations/seasonals and how code updates deploy.
- [ ] Transfer domain and deployment access to client-controlled account.
